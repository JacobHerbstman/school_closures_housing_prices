# All-home sales with condominiums audit

This audit preserves the broader transaction construction used while assessing
whether condominiums belong in the main study sample. It recovers verified
two-PIN condo-and-deeded-parking bundles, attaches the sparse public condo
characteristics, and applies the broad market-sale filters for 2006--2025.

The production graph does not depend on this task. The main sample is restricted
to single-card non-condominium residential properties because the historical
condo hedonics are too sparse and selectively observed for the 2008--2018 study
period. Existing condo diagnostics and external-composition audits may consume
this output without adding condo branches to the main cleaning code.

Run `make` from this task's `code/` directory.
