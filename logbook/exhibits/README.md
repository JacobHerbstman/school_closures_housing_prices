# Frozen logbook exhibits

Figures and tables cited by dated logbook entries, copied from exploratory
audit outputs so that later audit changes or deletions cannot alter what an
entry shows. `home_prices_twfe_2026-09-09/` holds that task's September 9
outputs. The other folders were copied on September 22, 2026. All are original
versions except `home_data_overview/`, which had already been rebuilt that day
on the September 22 clean sample (foreclosure auctions removed, REO resales
kept, unknown unit counts kept); its figures in September 7--9 entries
therefore reflect that sample rather than the one those entries describe.
Do not regenerate these files.
